# Samsung Insurance — сайт страховых продуктов

Премиальный адаптивный статический сайт (HTML/CSS/JavaScript, без сборки) в стиле samsung.com, представляющий два страховых продукта: страхование жизни «Лечение рака Плюс» (стандартный и упрощённый пакеты) и health-полис «New Plus One» (2607). Контент сайта — русский перевод информации из исходных корейских презентационных материалов о продуктах. Сайт готов к развёртыванию на GitHub Pages без дополнительных инструментов сборки.

## Структура проекта

```
.
├── index.html                 # Главная страница (Главная / О продукте / Пакеты / Сравнение / Материалы / Оформление / Контакты)
├── css/
│   └── style.css              # Стили сайта (дизайн-токены, glassmorphism, анимации, адаптивная вёрстка)
├── js/
│   └── main.js                 # Навигация, фильтры, скролл-анимации, лайтбокс галереи, валидация формы
├── assets/
│   ├── images/                   # Полноразмерные изображения слайдов (для карточек пакетов и лайтбокса)
│   │   └── thumb/                  # Облегчённые превью тех же слайдов (для сеток галереи/пакетов)
│   └── docs/                     # PDF-брошюры обоих продуктов для скачивания с сайта
└── README.md
```

Изображения именованы по продуктам: `slide-01…slide-15` — «Лечение рака Плюс», `newplus-01…newplus-06` — «New Plus One».

## Возможности

- Премиальный дизайн в стиле Samsung: анимированный градиентный hero, glassmorphism-элементы (шапка, бейджи, выпадающее меню), фирменные SVG-иконки, hover-эффекты карточек, шимер-заголовки, индикатор прогресса прокрутки
- Hero-секция, концепция продукта, ключевые преимущества, карточки пакетов с фильтрами по продуктовой линейке, таблица сравнения пакетов, галерея материалов (с лайтбоксом и счётчиком, тоже с фильтрами), FAQ, CTA-баннер, форма заявки на консультацию, расширенный футер
- Анимации появления элементов при прокрутке (со ступенчатой задержкой), анимированные счётчики, мобильное меню-гамбургер с раскрывающимся подmenu «Пакеты», смена стиля шапки при скролле
- Клиентская валидация формы (обязательные поля: имя, телефон, согласие на обработку персональных данных)
- Загружаемые PDF-брошюры для обеих продуктовых линеек (собраны из исходных материалов, оптимизированы по размеру)
- Изображения оптимизированы для GitHub Pages: полноразмерные версии сжаты и уменьшены (до ~1400px), отдельные лёгкие превью — для сеток галереи и карточек

## Локальный просмотр

Файл `index.html` можно открыть в браузере напрямую, но для корректной загрузки относительных путей рекомендуется локальный сервер:

```bash
# Python 3
python3 -m http.server 8000

# Затем откройте в браузере
# http://localhost:8000
```

## Развёртывание на GitHub Pages

1. Запушьте этот репозиторий на GitHub.
2. В настройках репозитория перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите источник `Deploy from a branch`.
4. Укажите ветку (например, `main`) и папку `/ (root)`, затем нажмите **Save**.
5. Через некоторое время сайт будет доступен по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

## Подключение формы заявок

Сейчас форма заявки на консультацию выполняет только клиентскую валидацию и показывает сообщение об успехе — бэкенда у статического сайта нет. Чтобы реально получать заявки, подключите форму к сервису вроде [Formspree](https://formspree.io) или [Getform](https://getform.io), либо к собственному серверному API. Логика отправки находится в `js/main.js`, в обработчике `form.addEventListener('submit', ...)`.

## Примечание

Сайт носит справочный характер и создан для представления продуктов на понятном языке. Указанные условия покрытия, размеры взносов и коэффициенты возврата — примерные и основаны на исходных материалах о продуктах; точные условия необходимо уточнять в официальном описании продукта и в тексте договора.

При отборе материалов для сайта используются только изображения официальных клиентских брошюр (с номером комплаенс-согласования, где применимо). Внутренние обучающие материалы с пометкой о запрете публикации в интернете, а также файлы, не относящиеся к продуктам Samsung Insurance, в сайт не включаются и не хранятся в этой ветке репозитория.
