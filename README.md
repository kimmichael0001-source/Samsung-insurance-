# Samsung Insurance — сайт страховых продуктов

Адаптивный статический сайт (HTML/CSS/JavaScript, без сборки), представляющий два страховых продукта: страхование жизни «Лечение рака Плюс» (стандартный и упрощённый пакеты) и health-полис «New Plus One» (2607). Контент сайта — русский перевод информации из исходных корейских презентационных материалов о продуктах. Сайт готов к развёртыванию на GitHub Pages без дополнительных инструментов сборки.

## Структура проекта

```
.
├── index.html              # Главная страница (Главная / О продукте / Пакеты / Сравнение / Материалы / Оформление / Контакты)
├── css/
│   └── style.css           # Стили сайта
├── js/
│   └── main.js              # Навигация, скролл-анимации, лайтбокс галереи, валидация формы
├── assets/
│   ├── images/                # Слайды о продуктах (slide-01…slide-15 — «Лечение рака Плюс»; newplus-01…newplus-06 — «New Plus One»)
│   └── docs/                  # Полная брошюра «New Plus One» (PDF) для скачивания с сайта
└── README.md
```

## Возможности

- Премиальный адаптивный дизайн в стиле Samsung (тёмно-синий + золотой акцент), для мобильных, планшетов и десктопа
- Hero-секция, концепция продукта, ключевые преимущества, карточки пакетов, таблица сравнения пакетов, галерея материалов о продукте (с лайтбоксом), FAQ, форма заявки на консультацию
- Анимации появления элементов при прокрутке, анимированные счётчики, мобильное меню-гамбургер, смена стиля шапки при скролле
- Клиентская валидация формы (обязательные поля: имя, телефон, согласие на обработку персональных данных)

## Локальный просмотр

Файл `index.html` можно открыть в браузере напрямую, но для корректной загрузки относительных путей рекомендуется локальный сервер:

```bash
# Python 3
python3 -m http.server 8000

# Затем откройте в браузере
# http://localhost:8000
```

## Развёртывание на GitHub Pages

1. Запушьте этот репозиторий на GitHub.
2. В настройках репозитория перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите источник `Deploy from a branch`.
4. Укажите ветку (например, `main`) и папку `/ (root)`, затем нажмите **Save**.
5. Через некоторое время сайт будет доступен по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

## Подключение формы заявок

Сейчас форма заявки на консультацию выполняет только клиентскую валидацию и показывает сообщение об успехе — бэкенда у статического сайта нет. Чтобы реально получать заявки, подключите форму к сервису вроде [Formspree](https://formspree.io) или [Getform](https://getform.io), либо к собственному серверному API. Логика отправки находится в `js/main.js`, в обработчике `form.addEventListener('submit', ...)`.

## Примечание

Сайт носит справочный характер и создан для представления продуктов на понятном языке. Указанные условия покрытия, размеры взносов и коэффициенты возврата — примерные и основаны на исходных материалах о продуктах; точные условия необходимо уточнять в официальном описании продукта и в тексте договора.

При добавлении пакета «New Plus One» на сайт была использована только официальная клиентская брошюра продукта (с номером комплаенс-согласования). Часть загруженных материалов представляла собой внутренние обучающие слайды с прямой пометкой о запрете публикации в интернете («[교육용] … 온라인 게시·전송할 수 없습니다» / «판매자교육용») — такие материалы намеренно не были включены в сайт и не сохранены в этой ветке репозитория.
